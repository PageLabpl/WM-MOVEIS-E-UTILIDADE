Por segurança, esse token fica salvo apenas neste painel (localmente) até o backend existir. Quando o backend for construído, ele deve ler esse token do servidor — nunca diretamente do navegador — para calcular o frete em tempo real na hora da compra.

Conexão com o Backend

Cole aqui a URL do backend depois de publicá-lo no Render (ex: https://wm-moveis-api.onrender.com). Se você está abrindo este painel a partir do próprio endereço do backend no Render, use o botão "Usar este mesmo domínio" — é a forma mais simples e evita qualquer configuração extra de CORS. Enquanto não configurar, o painel e o site continuam funcionando normalmente em modo local (dados salvos apenas neste navegador).
